# לוויתן אקורדים

מאמן אקורדים לגיטרה שמקשיב דרך המיקרופון: מציג אקורד, בודק כל פריטה ומסמן ✓ או ✗ עם רמז (איזה צליל חסר, איזה מיתר לבדוק).

- **תרגול**: בוחרים אקורדים, שלוש פריטות נכונות ברצף מעבירות לאקורד הבא.
- **שיר**: ייבוא מ-Tab4U / Ultimate Guitar (נשמרים רק האקורדים), טרנספוזיציה, קפו, תיקון אקורדים, מועדפים.
- **זיהוי חופשי** ו**טיונר**.

הכול רץ בדפדפן; שום צליל לא נשלח לשום מקום. `engine.js` הוא תרגום של מנוע הפייתון (whale_engine) ונותן החלטות זהות לו.
